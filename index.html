PROJECT 01

Photography Automation

Development of a Portable Commerce Photography Automation Robot

Overview

This project presents a portable robotic system designed to automate standardized product photography for e-commerce applications.

System

The robot provides four degrees of freedom to control camera height, camera angle, object rotation, and perspective translation. Shooting poses are automatically generated according to the dimensions of the target object.

Key Features

  • Portable 4-DOF photography robot
  • Automatic camera height and tilt adjustment
  • Automated multi-view object rotation
  • Perspective adjustment along the X-axis
  • Object-size-based shooting pose generation

Experimental Results

Repeated photography experiments demonstrated stable multi-view image acquisition and high positional repeatability, with pair Intersection over Union (IoU) values exceeding 0.90 in random repeated trials.
