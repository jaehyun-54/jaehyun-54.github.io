PROJECT 02

Photography Automation

ROBOTIC AUTOMATION · E-COMMERCE

Development of a Portable Commerce Photography Automation Robot

A portable 4-DOF robotic photography system for standardized e-commerce product imaging. The system automates camera height and tilt, object rotation, and perspective translation, with automatic pose planning based on object size.

Experimental evaluation demonstrated stable multi-view imaging and high repeatability, achieving high pairwise IoU values across repeated trials.

  • 4-DOF Robot
  • Photography Automation
  • Pose Planning
